# Fecal Microbiomes from Healthy Adult Consumers of Fruits and Vegetables Exhibit Fiber- and Donor-Specific Fermentation: “5 A Day” is Not Enough
## Sarah E. Blecksmitha, Karen M. Kalanetra, Cheng-Yu Weng, Christopher Suarez, Irnayuli R. Sitepu, Yirui Tang, Shawn Ehlers Cheang, Sophia Jiang, Karina Cerniogloc, Karla Damian-Medina, Jennifer T. Smilowitz, Carlito B. Lebrilla, David A. Mills, Danielle G. Lemay

## Main Scripts

**1_genius_cazy_families.R** -- makes a table of aggregated CAZy families and subfamilies from initial metagenomes

**2_genius_cazy_diversity.R** -- uses phyloseq to calculate cazyme family diversity from initial metagenomes

**3_genius_phyloseq.R** -- calculates shannon diversity from 16S sequencing for all fermentation samples

**3_genius_scfa.R** -- reads in SCFA data

**4_genius_monosaccharides.R** -- reads in monosaccharide data

**5_genius_merge_data.R** -- merges the glycomics, SCFA and shannon diversity data

**6_genius_pH.R** -- extracts and clean the pH data

**7_genius_cazy_permanova.R** --  computes permanova on cazyme profiles between responders and non responders

**8_genius_taxa_permanova.R** --  computes permanova on metaphlan taxonomy between responders and non-responders

**9_genius_FFQ** -- calculates HEI from FFQ and looks at consumption of test fibers
